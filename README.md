# ⚽ Elizium — Заедно за нашето игрище

Уеб портал за **доброволна дарителска кампания** за ремонт на футболното игрище
в комплекс Elizium. На този етап целта е **проучване** — да разберем колко съседи
биха се включили и каква сума бихме могли да съберем.

Порталът включва:

- Описание на целта, гаранция за връщане на средствата и уточнение, че това е проучване
- Галерия със снимки на игрището
- **Жива визуализация** на заявената сума спрямо целта (прогрес-бар + статистика)
- Форма за записване с полета: блок, вход, апартамент, име (по избор), сума
- Избор за **анонимност** и предпочитан начин на плащане (Revolut / в брой)
- Избор **как да се появи** участникът в списъка: блок/вход/апартамент, само име, или и двете
- **Защита от двойни записвания** — един апартамент се записва само веднъж
- Списък на неанонимните участници

---

## 🧩 Как работи

- **Frontend** — статични файлове (`index.html`, `assets/…`). Хостват се безплатно
  на GitHub Pages, Netlify, Vercel и др.
- **Backend** — **Google Таблица** + **Google Apps Script** (безплатно, само с
  Google акаунт). Скриптът записва данните в таблицата, прави проверката за
  дублиран апартамент и връща обобщената статистика и списъка на участниците.

Поверителността е защитена: анонимните записвания **не** се връщат в публичния
списък — скриптът филтрира само неанонимните участници.

## 🚀 Настройка (стъпка по стъпка)

### 1. Създайте Google Таблица

1. Отворете [sheets.new](https://sheets.new) (нужен е безплатен Google акаунт).
2. Дайте ѝ име, напр. „Elizium – записвания".

### 2. Добавете скрипта

1. В таблицата: меню **Разширения (Extensions) → Apps Script**.
2. Изтрийте примерния код и поставете **цялото** съдържание на файла
   [`google-apps-script/Code.gs`](google-apps-script/Code.gs).
3. Запишете (иконата 💾).

### 3. Внедрете скрипта като уеб приложение

1. Горе вдясно: **Внедряване (Deploy) → Ново внедряване (New deployment)**.
2. При „Изберете тип" (⚙️) изберете **Уеб приложение (Web app)**.
3. Настройки:
   - **Изпълнение като (Execute as):** Аз (Me)
   - **Кой има достъп (Who has access):** Всеки (Anyone)
4. Натиснете **Внедряване** и разрешете достъпа, който Google поиска
   (може да се наложи да натиснете „Разширени → Отиди към проекта (несигурно)" —
   това е нормално за собствен скрипт).
5. Копирайте показания **Web app URL**
   (изглежда като `https://script.google.com/macros/s/AKfy.../exec`).

### 4. Свържете портала със скрипта

Отворете [`assets/js/config.js`](assets/js/config.js) и поставете адреса:

```js
window.ELIZIUM_CONFIG = {
  APPS_SCRIPT_URL: "https://script.google.com/macros/s/AKfy.../exec",
  GOAL_AMOUNT: 11000,        // целева сума за ремонта
  RECOMMENDED_AMOUNT: 50,    // препоръчителна сума за участие
  CURRENCY: "€",
  CONTACT_TEXT: "",          // по избор: контакт за въпроси
};
```

### 5. Добавете снимки (по избор)

Сложете снимки на игрището в папка `assets/img/` с имена:

```
assets/img/pitch-1.jpg
assets/img/pitch-2.jpg
assets/img/pitch-3.jpg
```

Докато липсват, се показва примерна графика.

### 6. Публикувайте (безплатно) — GitHub Pages

1. Качете хранилището в GitHub (клонът вече е `claude/fundraiser-portal-setup-lvmrjy`;
   слейте го в `main` или публикувайте директно от него).
2. В GitHub: **Settings → Pages → Build and deployment**.
3. Source: **Deploy from a branch**, Branch: изберете клона и папка `/ (root)`.
4. След минута сайтът е достъпен на `https://<потребител>.github.io/Elizium/`.

Алтернативи: качете папката в [Netlify Drop](https://app.netlify.com/drop) или
свържете хранилището с [Vercel](https://vercel.com) — и двете са безплатни.

## 🔎 Преглед на записванията

Всички записвания се виждат директно във вашата **Google Таблица**, в лист
„Записвания". Оттам можете да ги преглеждате, редактирате, сортирате или
експортирате.

> ⚠️ **Не** използвайте опцията „Публикуване в интернет" (File → Share →
> Publish to web) на самата таблица — това би направило всички данни, включително
> анонимните, публично видими. Достъпът трябва да минава само през скрипта.

---

## ♻️ След промяна на скрипта

Ако редактирате `Code.gs`, трябва да внедрите наново:
**Deploy → Manage deployments → (моливчето ✏️) → Version: New version → Deploy**.
Така адресът (URL) остава същият.

---

## 🖥️ Локален преглед

Отворете `index.html` в браузър, или стартирайте локален сървър:

```bash
python3 -m http.server 8000
# после отворете http://localhost:8000
```

Без попълнен `APPS_SCRIPT_URL` сайтът се зарежда в режим на преглед (нулева
статистика, записването е неактивно).

## 📁 Структура

```
index.html                    – страницата
assets/css/styles.css         – стилове
assets/js/config.js           – настройки (попълва се от вас)
assets/js/app.js              – логика (форма, статистика, списък)
assets/img/                   – снимки + примерна графика
google-apps-script/Code.gs    – backend за Google Таблица
```
